一年戦争アーカイブ

U.C.0077年の暁の蜂起から0080年1月の終戦まで、18の戦いを時代順に並べた年表です。
TV版に加え、THE ORIGIN・08小隊・0080・サンダーボルトなどを含みます。
行を押すと、詳細と3D再現への入口が開きます。

損耗率
敗れた側、または損害の大きい側の値です。
数値の典拠
作中の描写と公式の設定に拠ります。一年戦争は兵力・損害の公式数値が少なく、確かめられなかった値は「—」です。
日付
作中で日付が示されない戦いは、前後の出来事から推定し、「推定」と書いています。
影響の段階
3段階の区分は編者の判断です。
話数
TV版は1979年放送の全43話の番号です。作品ごとに描写が食い違う場合は、TV版を基準にしています。
